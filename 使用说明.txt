英语跟读 · 本地发音精评

界面语言 / Interface language
首次使用双语版默认显示英文。点右上角「English / 中文」，选择「简体中文」或「English」，再点「应用」或「Apply」。程序立即切换并记住选择。
To change the interface language, choose “English / 中文” in the top right, select your language and choose “Apply”. Your selection is saved on this device.

开始练习
双击同一目录下的 ReadAloudStudio.exe。程序自带 Windows x64 运行环境、英语识别与评测模型，以及两款英国示范声音。断网也能练习。移动到其他位置时，请一起移动整个 ReadAloudStudio 文件夹。

1. 在「跟读练习」里点「换句 / 换段」。可以选择五个单句或三句范文「雨后的公园」，也可以粘贴自己的英文段落，再点「使用这段文本」。支持多行和最多 6000 个字符。Enter 换行，Ctrl+Enter 应用文本。「听整句示范」或「听整段示范」可用选中的声音朗读原文。
2. 在跟读文本下点麦克风按钮开始录音，读完点「结束并评测」。已有自己的朗读录音时，点「导入练习录音」。展开「录音设备」可切换或刷新麦克风。录音和导入 WAV 均支持最多 5 分钟。
3. 点原句或全文预览中的标记词。在「发音反馈」里，「回听这个词」播放你的录音，「听示范发音」播放示范词，「听句中读法」播放整句范读中这个词和前后相邻的词。例如在 Would you like a cup of tea? 中选 of，可以听到 cup of tea。句首和句尾只取本句内的相邻词。
4. 点「再读一次」，然后进入「两次对比」。可以连续播放两次的整段、同一句或同一个词。录音 A、B 的下拉框可以切换相同原文的其他历史录音。
5. 「练习记录」保存每次录音和对应结果。重开程序后可以继续回听。

选择示范声音
在「示范来源」中选择。默认 Cori 是英国女声，另一款内置英音是英格兰北部男声。美音来自本机已安装的 Windows 语音。这些声音支持单词、整句和整段示范。「听句中读法」直接截取所选声音朗读整句的音频，能听到实际的弱读、连读与节奏。
自带老师或自己的范读时，先在「换句 / 换段」中应用录音对应的英文原文，再到「示范来源」点音符按钮「导入自己的范读」，选择不超过 5 分钟的 WAV。定位完成后会显示找到的词数。你可以播放完整范读，也可以按句、词或语境选听。切换原文会载入那篇文章的范读列表和选择。未能可靠定位的部分可通过整段回听。范读保存在本机，不计入练习记录。
所有新练习录音都按英式 RP 参考词典评分。比如 bath 的目标是 /bɑːθ/，worth 是 /wɜːθ/，单独读 car 是 /kɑː/。「评分参考（英式）」显示这一次真正用于对齐的音标。选择美音或自带范读也沿用英式评分。
旧练习会显示「旧版美式」。打开这次练习，在评分卡点「按英式重评」，可以直接用已有原声得到英式参考分。重评沿用原来的录音、日期和练习记录，原评测另行保留。

整段怎样评
「←」切到上一句，「→」切到下一句。在「全文预览」里点一句即可跳转，当前句以浅绿色高亮。较长的文章可点「展开全文」，再点「收起全文」恢复紧凑预览。录音时可边读边翻句。评测后点「听本句」回放该句，点「听整段」回放完整朗读。展开「本句转写」可核对识别文本和差异，其中的「查看整段转写」可查看全文。
全文预览用红色下划线标记疑似发音偏差，用删除线标记疑似漏词，用橙色下划线标记整句待核对。点标记词即可回听该处的原声，与所选示范声音对照。段落中有多个标记词时，点发音反馈旁的「下一处标记」可按原文顺序循环查看，同一个词出现多次也分别定位。
想集中练某一句时，先用箭头或全文预览选中它，点「只重练这一句」，再点「录制这一句」或「导入练习录音」。每次重练单独保存。「原读与重练对比」显示原段中这句和本次重练的分数、所选词反馈及能定位的词间停顿。「原读 → 重练」会依次播放两次。点「返回全文」会回到原来那一句和所选词，整段录音和原分数保留。在练习记录里可以按句子序号找到重练。
每句使用本机的音素模型独立精评。段落上方显示已评分句数。所有分句都可靠、整段转写也没有明显多读时，才按原文词数对各句分数加权，给出整段参考分。
跳过一句时，界面可能标出「疑似漏读」。发音或录音不清导致定位不可靠时，该句会显示「待核对」。全文预览用橙色下划线标出这些分句，点一下即可检查。仍可查看其他已定位分句的反馈。程序按句末标点或换行分句，特别长的句子会优先在从句标点附近拆分，必要时按词数切短。
想先体验整段流程，可选「雨后的公园（3 句）」，在「导入练习录音」中打开 samples\after-the-rain.wav。若想把它用作范读，请从「示范来源」导入。

先试听 think 和 sink 的差别
保留默认目标句 I think it’s worth it.，用「导入练习录音」依次打开 samples\think-as-sink.wav 和 samples\worth-it.wav。这是一对合成测试录音，第一段把 think 刻意读成了 sink。进入「两次对比」，点 think，再点「连续回听 A → B」，即可对照音素提示听两遍原声。

怎样读反馈
「本地转写」显示词识别模型听到的内容，漏读、多读和替换提示来自与原句的文字对照。「发音反馈」使用另一套音素模型评估实际读音。即使 think 被正确转写，音素模型仍可能提示 /θ/ 听起来更接近 /s/。全文预览显示所有符合条件的词。分句大字默认优先突出两个值得回听的词，点选其他标记也能查看。时间边界为模型估计。
整句分数包括总分、准确、流利和韵律。建议结合同一句的原声变化观察进步。音量过低、静音或与原句明显不匹配时，程序会显示具体原因并隐藏分数。口音、说话速度、专名和录音条件都会影响判断。

评分依据与停顿
英式词典提供目标音素。程序把它们与原声对齐，再将音素匹配、语速、停顿、音高与音量等特征交给 OpenPronounce 英语蒸馏模型的评分器。英式词典中常见的强弱读、异读和元音前的连读 r 会按这次录音比对。缺少词典依据的词采用英式规则推测，界面会说明，也会淡化该词的错误判断。
四项分数沿用 scorer_en_student.json 的英文训练权重。作者在 speechocean762 的原版英语评测上报告，与人工评分的 Pearson 相关系数依次为总分 0.802、准确 0.766、流利 0.837、韵律 0.821。该结果对应上游原版评测。本地英式参考分、整段分数和诗歌表现力尚未通过独立的英式人工评分校准。
句内相邻词的对齐间隔超过 0.25 秒，会计入停顿特征。句子得分下方展示已定位词间的停顿计数、最长时长及两侧单词。相邻两句都可靠且首尾词可定位时，还会单列上一句末词和本句首词之间的间隔。句间间隔供回听参考，整段参考分没有单设句间停顿扣分项。换气、标点或诗歌留白都可能产生停顿，模型无法判断朗读者的表达意图。
模型与验证数据可查 https://huggingface.co/OpenPronounce/wav2vec2-base-phones-en#results 和 https://www.openslr.org/101/ 。

本机存储与性能
默认数据目录为 %LOCALAPPDATA%\ReadAloudStudio，可直接把这一行路径输入文件资源管理器的地址栏。练习录音保存在 recordings，自带范读保存在 examples，评测结果和范读定位保存在 practice.sqlite3。备份练习时先关闭程序，再复制整个数据目录。测试时可以用 READALOUD_DATA_DIR 指定独立的数据目录。
程序会自动选用可用的 NVIDIA 显卡。窗口右上角显示当前设备，例如「本地 GPU · RTX 5060」。每条新评测也会记录实际使用的 GPU 或 CPU。没有可用的 CUDA 设备时自动用 CPU，显存不足时会用 CPU 重新评测同一段录音，并在本次会话继续用 CPU。将鼠标停在右上角可以查看设备说明。
在这台 RTX 5060 和 Ryzen 5 8400F 上，同一条 2.11 秒样音在模型加载后各评测五次，中位耗时为 GPU 0.22 秒、CPU 0.62 秒。3.40 秒的真人样音分别约为 0.27 秒和 0.83 秒。首次使用还需初始化 CUDA 并加载两套模型，可能需要几十秒。

技术与来源
桌面端为 WPF / .NET 10，采集回放使用 NAudio / WASAPI。评测录音统一为 16 kHz 单声道 PCM，英音示范由 Piper 在本机合成为 22.05 kHz 单声道音频。评测端为 Python 3.11、PyTorch 2.8.0 CUDA 12.8 和 OpenPronounce 1.1.0。English distilled 音素模型与独立的 wav2vec2-large-960h 转写模型都支持 GPU 推理。音频预处理、对齐和统计评分使用 CPU。运行时只在本机环回地址通信，无需 API 密钥。
桌面源码在 source\Desktop，评测与存储逻辑在 engine\service.py，连续语音的分句定位在 engine\passages.py。开发和模型校验方法见 source\开发说明.txt。随包许可在 source\licenses、runtime\python 和各 Python 包的许可证目录内。
